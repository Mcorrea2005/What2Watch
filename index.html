How What2Watch ranks movies

Recommendation score = (normalized rating × quality weight) + (normalized popularity × popularity weight). The slider adjusts the two weights; they always add up to 1.

Rating is normalized to a 0–1 scale using TMDB's 0–10 rating. Popularity is normalized across the movies evaluated for this search. Explanations show how each result performed.

TMDB data changes over time. Low vote counts can make ratings less reliable. If runtime is missing, a movie cannot be verified against your runtime preference and is excluded from the filtered results.
